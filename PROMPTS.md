# AI prompt sequence

This file records the prompt sequence used to build the clone with Cursor.

1. Create a new project and complete the Airbnb take-home: pixel-perfect clone of https://airbnb-orpin-pi.vercel.app/ with listing page, photo tour, and lightbox. Include a Node/Express + MongoDB backend. Desktop only. The app must run smoothly.

2. Inspect the live reference visually (screenshots and rendered text). Do not copy bundled JS/CSS source. Recreate layout, colour tokens, type, motion, and keyboard behaviour from what the page shows.

3. Scaffold a MERN monorepo: Vite React client, Express API, Mongo with in-memory seed fallback so `npm run dev` works without Docker.

4. Implement the 2024-style Airbnb homepage: logo, Homes/Experiences/Services tabs, search pill, Pune and North Goa carousels, wishlist hearts, footer.

5. Implement `/listing/:id` to match Flat in Pashan: hero 5-photo grid, share/save, guest favourite, host row, highlights, sleep cards, amenities, calendar, sticky booking card, reviews, Carto map, house rules.

6. Implement Photo Tour overlay from “Show all photos” or any hero image, with room thumbs, section copy, and masonry photos.

7. Implement Lightbox from any tour photo: prev/next, `←`/`→`, Escape, focus on close, fade/slide motion.

8. Add architecture diagram, Cursor agent/skill configs, README, and verify the three views in the browser against the reference.
